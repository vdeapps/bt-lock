# Bluetooth Lock screen

## BUT

Faire une application en RUST, qui doit verrouiller une session lorsqu'un appareil bluetooth configuré s'éloigne de l'ordinateur.
L'application doit pouvoir faire des recherche sur les appareils bluetooth, puis configurer celui sélectionné.
Pour le lock on aura des paramètre comme (nom de l'application qui lock, delai avant lock, nombre d'essai, puissance du BT pour le lock ...).
Tu vois le genre d'application que je souhaite donc ajoute tout ce que tu penses nécessaires. Fait une belle interface, beau design, belle couleur, je veux aussi une icone dans la barre de notification quand je ferme l'application pour qu'elle reste en mémoire.
